# Subject sheet — Kangxi radicals (214)

**Pair with:** [`../referent-sourcing-brief.md`](../referent-sourcing-brief.md) — that's
the process (licensing, workflow, recording, done-definition). This sheet is only the
*what*: the referent list for this subject, and the few things about **this** subject
that change how you judge a good image.

**The subject in one line:** the 214 classical Kangxi radicals — the standard building
blocks Chinese and Japanese characters are indexed under. Each row below is one
referent (a *meaning*, e.g. `knife`, `rain`, `horse`). You're sourcing an image for the
**meaning**, exactly as the core brief describes.

---

## Read this before the list

**Source the meaning, not the character.** The referent is `fire`, not the shape 火 —
find a photo of *fire*, never a drawing of the glyph. (The glyph already has its own
stroke animation on the site; your image is the real-world thing it points at.)

**We're being deliberately generous about what "has a picture".** Traditionally a lot
of radicals are treated as pure structural bits, but most of them still *name an
everyday thing* — `lid`, `roof`, `box`, `beard`, `snout` — so we just source that thing.
Take the meaning at face value: **if you can picture it, source it.** We're not being
strict about classical etymology here — nobody's grading us on Kangxi orthodoxy.

That leaves really only one exception, marked in the table:

- **`abstract`** — numbers (`one`, `eight`), grammar words (`not`, `and`... handled
  elsewhere), a few pure concepts, and a couple of **sensitive** ones (see below). For
  these, **flag and move on** unless an obvious, uncontroversial image exists. When in
  doubt, skip and ask — don't force a misleading picture.

The four pure pen-strokes (`丨 丶 丿 亅`, marked **`stroke`**) are a special case rather
than a skip: there's no thing-in-the-world they name, but the *stroke itself* is the
referent — so source a clean **calligraphy / brushstroke** rendering of that stroke.
(This is the **one** place the "don't photograph the character" rule flips: for a bare
stroke the written form *is* the meaning.)

Everything else — blank, `broad`, `action`, `quality`, `stroke` — is fair game. That's
~189 of the 214. Many of the less-obvious ones have a **depiction hint** further down;
check there before you skip something.

**Type marks used in the table** (they map onto the core brief's type menu):

| mark | meaning | what to do |
|---|---|---|
| *(blank)* | concrete object or being | ~5 clear, typical examples |
| `broad` | umbrella meaning | a *varied* set (~5), no single narrow-reading shot |
| `action` | a verb | show the activity mid-action, not the object |
| `quality` | a colour / property | make the property the obvious point; neutral carrier |
| `abstract` | number / grammar / concept / sensitive | flag & skip; source only if an obvious clean image exists |
| `stroke` | a pure pen-stroke (`丨 丶 丿 亅`) | source a calligraphy/brushstroke of the stroke itself |

The type marks are a **starting call, not gospel** — if a row marked `abstract` clearly
has an honest, standard image, source it and note why; if a blank row turns out to have
no clean depiction, flag it. Judgement on the edge cases is exactly the skill this batch
is calibrating.

**A few sensitive ones.** `corpse` (44), `death` (78) and `slave` (171) are marked
`abstract` — **flag them, don't source**; there's no tasteful, unambiguous image and
they're not worth the risk. `blood` (143) and `ghost` (194) *are* sourceable but keep
them tasteful and neutral (a single drop / a clean medical image for blood; a classic
illustrated ghost is fine). Nothing gory, ever.

## Search-query hints (for `data/fetch-referent.py`)

Radicals are often a *bare noun*, which returns messy results. Two habits help:

- For an **object**, add an isolating phrase: `"knife isolated white background"`,
  `"axe on white"`, `"single feather"`.
- For an **action**, name a subject doing it: `"person running"`, `"man yawning"`,
  `"eating a meal"`.
- For a **quality/colour**, ask for a plain carrier: `"red colour swatch"`,
  `"bamboo forest"` (for the plant) vs `"green"` (for the colour) — keep them distinct.
- For a **`stroke`**, ask for the brushwork: `"Chinese calligraphy brushstroke"`,
  `"héng calligraphy stroke"` — the stroke is the subject here, so the character *is*
  what you want.

## Depiction hints for the less-obvious rows

These are the rows where the meaning isn't an obvious photo. Take the everyday thing the
word names:

**Objects (source the plain thing):**
- `lid` (8) — a pot or jar lid.
- `legs` (10) — a pair of human legs / the lower body.
- `cover` (14, 146) — a cloth or lid draped over something.
- `open box` (17) — an open-topped container / receptacle.
- `box` (22) — a plain box or open crate.
- `seal` (26) — a carved name-seal / stamp chop.
- `enclosure` (31) — a fenced or walled enclosure.
- `roof` (40) — a house roof.
- `inch` (41) — a ruler, or a close-up of a one-inch measure.
- `shelter` (53) — an open-fronted lean-to / simple shelter.
- `two hands` (55) — two raised or cupped hands.
- `snout` (58) — an animal snout (e.g. a pig's).
- `bristle` (59) — stiff fine hairs / a brush's bristles.
- `writing` (67) — a page of handwriting or calligraphy.
- `trigram lines` (89) — an I Ching trigram (three stacked lines).
- `sickness` (104) — someone unwell resting in bed.
- `track` (114) — an animal footprint / paw track.
- `and` → **beard** (126) — a beard. (The old pictograph is chin-whiskers; the everyday
  referent is simply a beard — source that, ignore the grammatical gloss.)

**Actions (show it happening):**
- `power; strength` (19) — visible exertion: a flexed arm, someone straining to lift.
- `wrap` (20) — wrapping something up / a wrapped bundle.
- `work; labour` (48) — someone at manual work (or a carpenter's square).
- `tap` (66) — tapping or striking something with a stick or hand.
- `life` (100) — new growth: a seedling sprouting.
- **movement radicals** — `go` (34), `go slowly` (35), `stride` (54), `step` (60),
  `footsteps` (105), `walk` (162) all mean *moving on foot*: a foot mid-step / someone
  walking. They overlap heavily, so a little variety across them is nice, but don't
  agonise — any clear "walking / on the move" shot works.

**Quality:**
- `even` (210) — *uniform / level*, all the same height: a neat row of equal-size,
  equal-height things, or a flush level edge. It's "uniform / aligned", **not** "equal
  weight" — so a tidy even row reads better than a balance scale.

**Strokes:**
- `丨 丶 丿 亅` (2, 3, 4, 6) — a single clean calligraphy brushstroke of that stroke on
  plain paper.

## Done, for this subject

Of the 214: **25** are `abstract` (flag, don't force — numbers, grammar, a few sensitive
ones). That leaves **~189 sourceable** — roughly 139 plain objects/beings, 26 actions,
14 qualities, 6 broad sets, and the 4 calligraphy strokes. A finished pass = every
sourceable row either has a set of ~5 verified images recorded, or is explicitly flagged
as not image-suitable with a one-line reason.
